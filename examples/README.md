# CaribouLite Examples
This folder contains examples categorized by programming languages:
- `c_api` - C API example and CMake build.
- `adsb_soapy` - C/C++ ADS-B example using SoapySDR.
- `gr_lora_receiver` - C++ GNU Radio LoRa receiver example.
- `python` - Python capture, spectrum and SoapySDR examples.

These are source examples; dependency/version checks and hardware RX/TX results
are tracked in [DOC-07](../roadmap.md#documentation-validation-backlog).
